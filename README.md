# Portfólio de Marco

Página de portfólio pessoal criada com HTML, CSS e JavaScript.

## Publicar no GitHub Pages

1. Crie ou use o repositório `ghost3864.github.io`.
2. Envie os ficheiros desta pasta para a raiz do repositório.
3. Em **Settings → Pages**, selecione a branch `main` e a pasta `/ (root)`.

O endereço será `https://ghost3864.github.io`.
